# Privacy Policy — Schema

**Last updated:** June 14, 2026

Schema ("Schema: Fast, Simple Todos") is a task management app for macOS developed by Shubhdeep Sarkar.

## Data collection

Schema does **not** collect, transmit, or sell any personal data. All task and list data is stored **locally on your Mac** using SwiftData. No accounts, analytics, or third-party SDKs are used.

## Notifications

If you enable reminders, Schema schedules local macOS notifications on your device. Notification permission is requested only when you use reminder features or grant access in Settings. Notification content (task titles) stays on your device.

## Data storage

Your data is stored in the app's local SwiftData database. Uninstalling the app removes this data.

## Contact

For privacy questions, contact the maintainer via the GitHub repository issues page.
