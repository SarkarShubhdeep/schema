# v0.2 Roadmap

Integration branch: **`develop`**  
Active slice: **`feature/task-detail-view`**  
Release target: **0.2.0** (internal TestFlight on macOS)

Track shipped work in [CHANGELOG.md](../CHANGELOG.md) under `[Unreleased]`. Close or update items in [KNOWN_ISSUES.md](KNOWN_ISSUES.md) and [FEATURES.md](FEATURES.md) as they land.

## How to work

1. Branch off `develop`: `feature/*`, `fix/*`, or `enhancement/*`
2. Merge back into `develop` when a slice is done
3. Bump `CURRENT_PROJECT_VERSION` only when uploading a TestFlight build
4. Bump `MARKETING_VERSION` to `0.2` when cutting the release on `main`

## Priority order

Work in delivery order below. Phase 0 is required **before Phase 2** (new `@Model` fields). Phase 1 needs no migration.

| Phase | Name | Branch | Model changes? |
|-------|------|--------|----------------|
| **1** | Detailed task view | `feature/task-detail-view` | No |
| **0** | SwiftData migration + recoverable launch error | `feature/swiftdata-migration` | Infrastructure only |
| **2** | True manual sort (drag-to-reorder) | `feature/task-drag-reorder` | Yes — `order: Int` on `SchemaTask` |
| **3** | List reordering | `enhancement/list-reorder` | No — `SchemaList.order` exists |
| **4** | Reliability & polish | `enhancement/error-handling` / `fix/*` | No |
